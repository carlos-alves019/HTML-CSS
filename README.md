# Repositório: web-projects-html-css

# 🇵🇹 Descrição
Projetos de prática em HTML e CSS, focados em desenvolvimento web,
layouts responsivos e interfaces modernas. Inclui exercícios de estrutura
semântica, estilização com CSS, criação de páginas funcionais e páginas
estáticas para aprimorar habilidades de Front-End.

# 🇵🇹 Tecnologias Utilizadas
- HTML5
- CSS3

# 🇵🇹 Funcionalidades
- Estrutura semântica das páginas
- Layouts responsivos usando Flexbox e Grid
- Páginas estáticas com conteúdo fictício
- Navegação simples entre páginas
